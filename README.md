# CALICO Spring '26 Contestant Submissions

This repository contains all contestant submissions from the CALICO Spring 2026.

## Structure

```
<team_id> - <team_name>/
  <problem_name>/
    <submission_id>_<filename>.<ext>
```

- **Team directories** — Each top-level directory is named `<team_id> - <team_name>` (517 teams total).
- **Problem directories** — Within each team, subdirectories are named by problem (e.g. `laser_main`, `grid_bonus`).
- **Source files** — Individual submissions, prefixed with their submission ID.
